# 标签栏溢出布局优化

## 需求背景

当打开的文件数量过多（>10 个）时，标签栏水平溢出导致整体布局异常：
- 标签无限扩展，工具栏按钮被挤压到边缘甚至不可见
- 标签列表虽有滚动条但几乎不可见，用户无法感知还有更多标签
- 切换标签后激活的标签可能不在可视区域内

## 设计方案

采用 **滚动标签栏 + 渐变遮罩 + 自动滚动** 方案（参考 VS Code / Chrome 标签栏行为）。

### 核心策略

1. **渐变遮罩指示器** — 标签容器左右两侧显示渐变遮罩，提示用户还有更多内容可滚动
2. **隐藏原生滚动条** — 视觉更干净，依赖鼠标滚轮和触摸滑动
3. **鼠标滚轮横向映射** — 在标签列表上滚动鼠标滚轮时，垂直滚动映射为水平滚动
4. **激活标签自动滚动** — 切换标签时自动将激活的标签滚动到可见区域
5. **窗口尺寸自适应** — 窗口 resize 时重新检测遮罩状态

## 变更清单

| 文件 | 改动说明 |
|------|---------|
| `src/styles.css` | `.app-shell` 添加 `grid-template-columns: minmax(0, 1fr)` 约束 grid 列宽防止内容撑大溢出；`.document-tabs` 添加 `position: relative` + `overflow: hidden`，伪元素 `::before`/`::after` 渐变遮罩，`.has-scroll-left`/`.has-scroll-right` 类控制遮罩显隐；`.document-tab-list` 隐藏滚动条 |
| `src/documents.ts` | 新增 `scrollActiveTabIntoView()` / `updateTabScrollIndicators()` 辅助函数；`renderDocumentTabs()` 末尾调用两者；`setupDocumentTabs()` 添加 `scroll`/`wheel`/`resize` 事件监听 |

## 验收标准

1. 打开 10+ 个标签时，右侧渐变遮罩出现，提示还有更多标签
2. 鼠标滚轮可在标签栏上横向滚动
3. 切换标签时，激活的标签自动滚动到可见区域
4. 滚动到最左/最右时，对应侧遮罩消失
5. 工具栏按钮（新建、打开、保存等）始终可见不被挤压
6. 窗口缩放后遮罩状态正确更新
